# الساعة فوق التطبيقات

من إعدادات MuslimTV ← **التوقيت** ← **الساعة فوق التطبيقات** يمكن إظهار الساعة العائمة أو إخفاؤها. تظهر افتراضيًا فوق التطبيقات الأخرى في الزاوية العليا اليمنى، بخلفية خضراء داكنة شبه شفافة وحد ذهبي خفيف. لا تستقبل اللمس أو أزرار الريموت.

تستخدم توقيت وينبيغ نفسه الذي يستخدمه جدول الصلاة، والأرقام العربية، وتُحدّث الوقت مرة كل دقيقة. تختفي عند إطفاء الجهاز وعند عرض واجهة MuslimTV أو شاشة توقفه لأنهما تعرضان الوقت أصلًا. إذا ظهر تنبيه الأذان، ينتقل التنبيه أسفل الساعة. يعمل العرض عبر خدمة إمكانية الوصول الخاصة بمساعد Fire TV، لذلك يحتاج أن تبقى الخدمة مفعّلة.
